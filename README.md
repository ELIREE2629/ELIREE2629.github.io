# Elic's Portfolio

A responsive personal portfolio website built as part of the ECPI University Software Development program.

## Features
- Dynamic project rendering from JavaScript objects
- Dark mode with persistent preference (localStorage)
- Welcome modal on page load
- Interactive contact form with loading animation
- Responsive design
- Session storage for project data

## Technologies Used
- HTML5
- CSS3
- JavaScript
  - DOM Manipulation
  - JSON / sessionStorage
  - localStorage
  - Event Listeners

## How to Run
1. Clone or download the repository.
2. Open `index.html` in any web browser.
3. No additional dependencies or build steps required.

This project demonstrates client-side data management, dynamic rendering, and user preference persistence.
